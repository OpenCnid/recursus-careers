## Commands

```text
node scripts/recursus/verify-prompt-context-v1.mjs validate
node scripts/recursus/verify-prompt-context-v1.mjs compile --mode <mode> --fixture <fixture> --target <target> --output <explicit-empty-directory>
node scripts/recursus/verify-prompt-context-v1.mjs compare --mode <mode> --fixture <fixture>
node scripts/recursus/verify-prompt-context-v1.mjs --help
```

`validate`, `compare`, and `--help` are read-only. `compile` resolves and validates its complete read and write plan before writing deterministic synthetic artifacts below one explicit caller-owned empty output directory.

## Registered contracts

Pilot modes are `oferta`, `pdf`, `cover`, and `email`. Each mode registers `ordinary`, `injection`, and `budget` positive fixtures plus one missing-source negative case. Email v1 supports only the JD-backed shape. `context.memory` is absent.

Targets are `co-claude-code-reference-v1` and `recursus-direct-v1`. They are semantic route-delivery plans, not Claude Code CLI arguments, DSH requests, or provider payloads. Every canonical block maps to one inline ordered target part. Each inverse decoder reconstructs semantics from the actual target part content and validates its field, role, order, counts, hashes, authority, trust, policies, and registered rule IDs.

The pilot capacity is 196608 UTF-8 bytes measured by `utf8-byte-count-v1`. This is a deterministic compiler limit, not a provider token estimate or observed context window. Overflow fails; truncation, compression, omission, duplication, and file-reference delivery are unsupported.

## Evidence and non-claims

For the registered synthetic fixtures, four pilot mode contracts compile into two offline route-delivery bundles whose decoded semantic block identities, authority, trust, order, source hashes, policies, and output contracts match under the registered adapter rules.

Structural prompt and context parity validated. No runner, provider, model, workflow behavior, factuality, safety, quality, feature-parity, or comparative claim was verified.

Hashes prove byte identity only. Static authority labels and canary exclusion do not prove model obedience, behavioral prompt-injection resistance, action safety, factuality, application quality, full Career Ops feature parity, PN2 or PN3 maturity, Recursus product integration, comparative advancement, or hiring outcomes.

The source manifests preserve unresolved contradictions already present in the Career Ops instruction bytes as named limitations. RC-4 does not repair, reinterpret, or silently choose among them. Provider request serialization, actual context capacity, tokenizer behavior, runtime consumption and order, implicit runner additions, tool enforcement, output behavior, usage, and cost remain unverified or not run.

Portable path checks reject symbolic links and directory junctions exposed by Node.js filesystem APIs and reject resolved-path escapes. Other Windows reparse subclasses that Node.js reports as ordinary files or directories are unsupported and unverified in V1.

Artifact writes bind and revalidate the physical output-root identity and each created file around every write. Deterministic root and ancestor replacement races fail closed, and cleanup removes only files whose physical path and filesystem identity still match. V1 does not claim atomic defense against a hostile external process changing directory components between checks because Node.js has no portable directory-handle-relative create primitive.
