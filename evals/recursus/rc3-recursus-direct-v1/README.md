No provider or Recursus runtime was invoked by either V1 dry run.

No V1 record supports a Recursus execution, oracle, factuality, safety, quality, prompt-parity, feature-parity, advancement, comparative-performance, application-quality, or hiring-outcome claim. Hashes in the historical files establish byte identity only.
